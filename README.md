Невеликий React-проєкт з формою реєстрації, створений за допомогою Vite.  
У проєкті використовується Formik для роботи з формою та Yup для валідації даних.

Функціональність:

- введення імені, email та пароля
- перевірка правильності введених даних
- повідомлення про помилки
- відправка форми
- очищення форми після успішної відправки
